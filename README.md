# Study App — SwiftUI Custom Layout

Учебный проект: кастомный Layout в SwiftUI.

## 🚀 Возможности
- Первый элемент на всю ширину экрана, остальные по 2, последний элемент (если чётное кол-во) распологается на всю ширину
- Модификаторы
  - `AppConstants`
- Компоненты
  - `CategoriesView`
  - `SleepCardItems`
  - `SleepCardView`
- Работа с цветом
  - `extension Color(hex:)`
- Custom Layout
  - `FeaturedGridLayout` - first is full screen, next: 2 column, if count % 2 == 0 => last is bigger too


## 🛠 Технологии
- SwiftUI
